# Bright Future Academy — School Website Starter

A responsive sample school website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — website content and structure
- `style.css` — colors, layout, and responsive styling
- `script.js` — mobile navigation, current year, and demo contact form

## Run on your computer
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Test on both desktop and mobile widths.

## Important before publishing
- Replace "Bright Future Academy" with the school's real name.
- Replace all sample contact details and program information.
- Replace the `info@example-school.com` address in `index.html` and `script.js`.
- Add only photos and school information you have permission to use.
- Test every navigation link and the contact form.
- The contact form uses `mailto:` and depends on the visitor having an email app configured. It does not send messages through a server.

## Publish
You can publish a static website using GitHub Pages or Netlify. Check each platform's current instructions and usage limits before deployment.
